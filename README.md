# venue-scheduling-demand-change · 场馆排期与需求变更

> 工程技术与创新应用项目 · FDE 现场调研交付物仓库
> 案例：上海东浩会展经营有限公司 · 场馆档期申请（意向询期 → 占档确认 → 合同审核 → 进撤场计划），案例编号 `dlg-venue-schedule`

## 这是什么

围绕六位受访者（顾明岚·业务负责人、林亦舟·一线服务专员、唐映秋·项目流程协调员、秦芮·数字化工程师、傅景·审核与质量负责人、叶书·客户协同代表）的访谈事实（f00–f55），完成课堂要求的 8 项交付：现状还原 → 痛点量化 → 流程图（改造前/后）→ 需求分析 → 项目设计 → 三档报价与投入产出测算。

## 怎么"跑"

本仓库是**文档交付型仓库**，无需安装依赖：

- 流程图 PNG / docx 直接下载查看
- `docs/briefing/` 与 `examples/` 下的 HTML 用浏览器打开即可（可打印 / 另存 PDF）
- `data/` 下 json / csv 可用 Excel 或任意 JSON 工具打开

> 因此框架中的 `src/`、`tests/`、`scripts/`、`config/` 本仓库暂不包含；若后续把只读核对助手原型开源，会按同框架补充。

## 关键口径

- 三个 docx 与报价均为**合成演练口径**（含税报价为演练数字），封面已标注
- 全部事实编号 f00–f55 与《调研报告》一一对应，可交叉核对
- 商业论证链：报价及范围 → 月运行成本 → 业务量/节省时间/采用率/兑现假设 → 首年净收益/ROI/回本期 → 待验证假设（A-1～6）
