1. **口径咨询**（30 秒）：问「装卸口占用的判定口径是什么？」→ 回答带来源引用与「最终结论需人工复核确认」页脚。
2. **预订全流程**（2 分钟）：问答页切「智能体模式」，填场地/装卸口/活动与进撤场时间 → 5 步工具轨迹 → 🛑 强制中断确认卡片 → 点「确认创建」→ 草稿创建（状态 draft，不生效）→ 提交复核。
3. **规则拦截**（1 分钟）：把场地改为主馆、时间段与已确认档期重叠 → 冲突检测阻断并给出依据条款。
4. **越权验证**（30 秒）：用 staff 重复第 2 步 → 工具层返回 denied，提示“试点期仅协调员/管理员可用”。
5. **审计留痕**（1 分钟）：管理员进审计页 → 看到提问原文、工具轨迹、耗时与版本。

## 五、可用性与排错

| 现象 | 原因 | 处理 |
|------|------|------|
| 打开是 403 | 链接缺 `?sharecode=` | 用第一节完整链接 |
| 页面能开但接口 401 | 浏览器未带 Cookie（禁用了 Cookie / 无痕拦截） | 允许 Cookie 后重新登录；接口也接受 `Authorization: Bearer` |
| 首次打开慢（3~5 秒） | 沙箱冷启动 | 等 5 秒刷新；后续请求在 1 秒内 |
| 登录返回 200 但随即 401 | 令牌被网关注入头覆盖 | 本版已改为 Bearer 与 Cookie 双通道校验 |

## 六、部署与回退

```bash
cd deploy
pip install -r requirements.txt
python run.py            # 读 PORT 环境变量，默认 8500
```

- 部署包自带 SQLite 库，无需外部数据库；备份即备份 `deploy/data/admin.db`。
- 回退：本系统是只读辅助层，停止服务即完成回退，对原排期业务零影响；草稿不生效，不会留下已锁定档期。
- 详细运维步骤（账号、备份、故障处理）见 `docs/9-上线交付运行手册/上线交付运行手册.docx`。
