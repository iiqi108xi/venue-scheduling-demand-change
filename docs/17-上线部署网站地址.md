## 三、上线验证记录（2026-11-06 实测）

1. 分享链接访问 → 302 → 登录页 200（`登录 · 场馆档期排期智能体管理后台`）。
2. POST /api/auth/login（staff）→ 200 + JWT 签发。
3. 智能体模式提交预订草稿 → create_schedule_draft 强制中断生成确认单 → 人工确认后草稿创建（状态 draft 不生效）→ 提交人工复核。
4. 权限：staff 调管理员接口 403；未登录 401。

## 四、演示要点（5 分钟）

1. **口径咨询**：知识库检索 + 引用作答 +「最终结论需人工复核确认」页脚。
2. **预订全流程**：智能体模式填草稿参数 → 5 步工具轨迹 → 🛑 强制中断确认卡片 → 点击「确认创建」→ 草稿创建（不生效）→ 提交复核。
3. **规则引擎拦截**：主馆时间重叠草稿 → 冲突检测阻断。
4. **越权**：切 staff 重复步骤 2 → 角色门禁拒绝。
5. **审计**：管理员查看对话审计（提问原文 / 工具轨迹 / 版本）。
