# 管理后台（服务端渲染）· 页面清单 + 接口清单

> 项目：场馆档期排期智能体系统 · 管理后台 v1
> 日期：2026-10-30
> 状态：⏳ 待业务方确认后分批开发
> 业务硬约束（贯穿所有页面与接口）：智能体仅做冲突提示，**不自动锁档、不签约、不对外承诺容量，所有业务结论必须人工复核确认**。

## 技术选型（建议，待确认）

| 项 | 选型 | 说明 |
|---|---|---|
| 后端 | FastAPI + Jinja2Templates（SSR） | 服务端渲染，对标企业 SaaS 风格（左侧导航 + 顶栏 + 卡片表格） |
| 数据库 | SQLite（SQLAlchemy，可无缝切 PostgreSQL） | 首版演示用 SQLite，零部署成本 |
| 鉴权 | JWT（pyjwt）+ HttpOnly Cookie | 页面走 Cookie，API 走 Bearer；接口级依赖注入强制校验角色 |
| 密码 | pbkdf2_sha256（passlib） | |
| 向量库 | FAISS + 本地持久化 + 切片向量存库 | 删除文档时同步重建索引 |
| LLM/Embedding | 复用阶段1的可配置供应商适配层（含 mock 离线模式） | |
| 前端 | Jinja2 + 原生 CSS（SaaS 风格）+ 少量原生 JS（fetch 调 API） | 不引入重型前端框架 |

## 角色与权限矩阵

| 页面/能力 | 一线员工 | 管理员 |
|---|---|---|
| 登录 / 修改自己密码 | ✅ | ✅ |
| 档期问答（智能体对话） | ✅ | ✅ |
| 提交档期草稿 / 查看自己的草稿 | ✅ | ✅ |
| 查看自己的问答记录（只读） | ✅ | ✅ |
| 查看所有人的问答记录 + 标记风险 | ❌ | ✅ |
| 知识库上传/删除 | ❌ | ✅ |
| 提示词模板编辑 | ❌ | ✅ |
| 用户管理 | ❌ | ✅ |

权限实现原则：**所有 API 接口通过 FastAPI 依赖（`get_current_user` / `require_admin`）做接口级校验；页面路由同样经依赖校验；前端只做展示，不做权限判断。**

## 一、页面清单（服务端渲染）

| 编号 | 页面 | 路由 | 角色 | 内容 |
|---|---|---|---|---|
| P01 | 登录页 | `/login` | 公开 | 账号密码登录；登录成功写入 HttpOnly JWT Cookie 并跳转 |
| P02 | 档期问答页 | `/chat` | 员工/管理员 | 与智能体对话：提问 → 展示回答（带 [来源N] 引用）+ 可展开查看召回的知识库片段；回答页脚固定人工复核提示 |
| P03 | 档期草稿页 | `/drafts` | 员工/管理员 | 提交档期草稿（项目/场地/时间窗/装卸口/进撤场时间等），查看自己提交的草稿列表（状态：草稿） |
| P04 | 我的问答记录（只读） | `/chat/history` | 员工/管理员 | 自己的历史会话列表 + 会话详情（只读） |
| P05 | 知识库管理页 | `/admin/kb` | 管理员 | 上传 Markdown/PDF（拖拽或选择）；文档列表：文件名、类型、上传时间、上传人、切片数量、入库状态（处理中/已入库/失败）；单条删除（同步删除向量与切片） |
| P06 | 提示词模板管理页 | `/admin/prompt` | 管理员 | 在线编辑系统提示词（多行文本）；显示当前生效版本与修改时间；保存即全站问答立即生效；支持一键恢复默认模板（默认模板内置风控边界原文） |
| P07 | 对话审计页 | `/admin/audit` | 管理员 | 筛选：员工账号（下拉）、起止时间；会话表格：时间、账号、提问摘要、标记状态；操作：查看完整详情、标记/取消"疑似风险记录"（原因必填） |
| P08 | 审计详情页 | `/admin/audit/sessions/{id}` | 管理员 | 完整溯源：提问原文、召回的知识库片段（含所属文档及版本号）、大模型原始回答全文、访问人、时间戳、提示词模板版本；风险标记与原因 |
| P09 | 用户管理页 | `/admin/users` | 管理员 | 用户列表、新增用户（账号/初始密码/角色）、启停用（首版简单实现） |

导航：员工登录后仅见 P02/P03/P04；管理员可见全部。无权限访问的页面与接口一律 403，不做前端隐藏式"伪权限"。

## 二、接口清单（REST，均带接口级角色校验）

### 认证
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| POST | `/api/auth/login` | 公开 | 账号密码 → JWT（同时返回 token 并写入 HttpOnly Cookie） |
| POST | `/api/auth/logout` | 登录用户 | 清除 Cookie |
| GET | `/api/me` | 登录用户 | 当前用户信息与角色 |

### 知识库（核心 RAG）
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| POST | `/api/kb/documents` | 管理员 | multipart 上传 .md/.pdf；后台异步：解析 → 500 字切片（重叠50）→ 向量化 → 写 FAISS + kb_chunks；返回文档 ID |
| GET | `/api/kb/documents` | 管理员 | 文档列表（文件名/上传时间/上传人/切片数/状态） |
| DELETE | `/api/kb/documents/{id}` | 管理员 | 删除文档：同步删除 kb_chunks 与 FAISS 中对应向量（索引重建） |
| GET | `/api/kb/search?q=` | 管理员 | 调试用：BM25+向量混合检索预览 |

### 提示词模板
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/prompt-template` | 管理员 | 当前生效模板全文 + 版本号 + 修改时间 |
| PUT | `/api/prompt-template` | 管理员 | 保存新版本（新增版本记录，不改历史）；问答管线每次请求实时读库，保存即全站生效，无需重启 |
| POST | `/api/prompt-template/reset` | 管理员 | 恢复默认模板（内置业务风控边界原文） |

### 档期问答（审计留痕核心）
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| POST | `/api/chat` | 员工/管理员 | 提问 → 实时读取生效提示词模板 → 混合检索 top3 → LLM 生成 → **完整留痕后**返回。留痕字段：提问原文、召回片段（含文档ID/名称/版本号/切片号）、大模型原始回答全文、访问人、使用的提示词模板版本、双时间戳 |
| GET | `/api/chat/sessions` | 员工=本人；管理员=全体 | 会话列表（支持 user_id/start/end 筛选） |
| GET | `/api/chat/sessions/{id}` | 员工=本人；管理员=全体 | 会话完整详情（员工只读自己的，且不含风险标记操作） |

### 审计
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/admin/audit/sessions?user=&start=&end=&flag=` | 管理员 | 全量历史会话筛选（账号/起止时间/风险状态） |
| POST | `/api/admin/audit/sessions/{id}/flag` | 管理员 | 标记疑似风险记录（类型：排期冲突误判/越权承诺/违规口径；原因必填） |
| DELETE | `/api/admin/audit/sessions/{id}/flag` | 管理员 | 取消标记 |
| GET | `/api/admin/audit/sessions/{id}/full` | 管理员 | 完整溯源数据（P08 数据源）：提问/召回片段/原始回答/访问人/文档版本/模板版本 |

### 档期草稿
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| POST | `/api/drafts` | 员工/管理员 | 提交档期草稿（仅草稿状态，不触发任何锁定动作） |
| GET | `/api/drafts` | 员工=本人；管理员=全体 | 草稿列表 |

### 用户管理
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/admin/users` | 管理员 | 用户列表 |
| POST | `/api/admin/users` | 管理员 | 新增用户（账号/密码/角色） |
| PATCH | `/api/admin/users/{id}` | 管理员 | 启用/停用/重置密码 |

## 三、数据表（首版）

`users`（角色 employee/admin）、`kb_documents`（含 doc_version 递增）、`kb_chunks`（切片+向量+faiss 位置）、`prompt_templates`（版本化，is_active 指向生效版）、`chat_sessions`、`chat_messages`（question/retrieved_chunks/llm_raw_answer/prompt_template_version/created_at）、`risk_flags`（会话ID/类型/原因/操作人）、`schedule_drafts`。

## 四、默认提示词模板（随系统内置，可在 P06 修改）

> "你是会展场馆档期排期助手，仅能依据知识库内的制度条文给出结果；只能输出档期冲突、缺项清单、文档来源位置；严禁自动判定锁档、签约、承诺场地容量；遇到制度无明确规则时，直接回复「制度中未找到对应口径，请人工复核」；每一条结论都必须附上原文引用来源，不得自行编造排期规则。"

另在渲染层强制追加（不受模板编辑影响）："⚠️ 以上为系统候选提示，最终结论需要人工复核确认。"——保证即使模板被改坏，人工复核底线仍在。
