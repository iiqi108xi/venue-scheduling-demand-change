## 五、三分钟口头汇报提纲

1. **场景与约束**：场馆排期核对靠三处来源人工比对；硬约束是"不能改造系统、不能自动锁档、必须人工确认"。
2. **方案**：只读归集 + 规则引擎判冲突 + LLM 只做理解与表达 + 确认门强留痕。
3. **关键设计**：6 工具执行循环；建草稿前强制中断；双 precheck token 防跳步；确认后重跑校验。
4. **证据**：30 条评测 30/30；硬冲突拦截有口径编号；staff 越权 403；审计可回查每次工具调用。
5. **边界**：MVP 未做并发压测与真实连接器，属已知遗留，写在报告里而不是藏起来。
